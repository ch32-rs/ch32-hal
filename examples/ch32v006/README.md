# CH32V006

## Boards

CH32V006K8U6-EVT-R0

- LED requires jumper wire to connect to any GPIO

## Target

[`riscv32emc-unknown-none-elf.json`](riscv32emc-unknown-none-elf.json) enables `xwchc`, WCH's compressed byte and halfword loads and stores. QingKe V2C implements the extension (QingKe V3 manual, table 1-1).
